# AutoLoc

AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

## Objectif du projet

L'objectif est de développer une application Java/Spring Boot permettant de gérer les clients, les véhicules, les réservations, les agences et les utilisateurs.

## Acteurs principaux

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Technologies prévues

- Java 17
- Spring Boot
- Maven
- MySQL
- Git/GitHub
- Postman
